# mUSDC lending knowledge

This module owns the deployed BTC/mUSDC Morpho market: asset/share units,
interest, health, liquidation, bad debt, and future-operation requirements.
mUSDC is the Native Bridge representation of Ethereum USDC; it is not MUSD and
never participates in classic MUSD troves, TCR, Stability Pool, or redemptions.

Qualified Level 3 review accepted the bounded module and three Contract roots
under lending evidence review. Knowledge support remains `proposed`, and the module exposes no
reader, borrower, or liquidator writer. Start with
[`generated/reference.md`](generated/reference.md).
