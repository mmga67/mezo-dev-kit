# Synthetic widget catalog

This is a documentation fixture, not a canonical MDK module. It demonstrates
the v0.4 resource roles and stable-reference flow with fictional widget data.
It is excluded from `knowledge/index.json` and establishes no Mezo or product
support.

Use the parent
[`knowledge-authoring example README`](../README.md) and
[`knowledge-authoring guide`](../../../KNOWLEDGE_AUTHORING.md). Do not use this
README as a module-creation shortcut: a real module first needs human-approved
domain ownership, task scope, evidence requirements, and review gates.
