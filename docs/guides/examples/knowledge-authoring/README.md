# Synthetic knowledge-authoring example

`synthetic-widget-catalog/` is a documentation-only v0.4 module used by the
[knowledge-authoring guide](../../KNOWLEDGE_AUTHORING.md). It is deliberately
outside the canonical `knowledge/` tree and root catalog. Every name, value,
timestamp, source, and observation is fictional; nothing here is Mezo evidence
or a support claim.

The example separates an immutable synthetic source artifact, source catalog,
bounded evidence, canonical-shaped record, local schema, generated projection,
and review material. The record remains unsupported and pending review even
when the structural, semantic, and drift checks pass.

Do not copy the example lifecycle values, source classification, or module ID
into a real module. Follow the guide to copy the module into a temporary
repository, exercise it, and delete that disposable directory afterward.
